# Rock-Paper-Scissors---Python-game

This is a beginner-friendly command-line Rock Paper Scissors game built using Python.
The project was created to practice Python fundamentals and improve logical thinking.

## 🔹 Features
- Player vs Computer gameplay
- Random computer choices using Python
- Score tracking
- Input validation
- Replay option

## 🔹 Concepts Used
- Conditional statements
- Loops
- Python `random` module
- Basic input/output handling

## ▶️ How to Run the Project
1. Make sure Python is installed on your system
2. Clone this repository or download the code
3. Open a terminal in the project folder
4. Run the command:

```bash
python rock_paper_scissors.py
